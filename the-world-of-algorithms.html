Key Concepts

  • Algorithm: A clear sequence of steps used to solve a problem.
  • Divisor: A number that divides another number with remainder zero.
  • GCD: The greatest positive number that divides both given numbers.
  • LCM: The smallest positive number that is a multiple of both given numbers.
  • Prime number: A whole number greater than 1 with exactly two positive divisors: 1 and itself.
Euclid's division algorithm
gcd(m,n) = gcd(n, remainder when m is divided by n).
When the remainder becomes 0, the last non-zero divisor is the GCD.
LCM formula
LCM(m,n) = (m × n) ÷ GCD(m,n)

Exercise Set 11.1 — Addition Algorithm

Q1. Follow the written algorithm to add two four-digit numbers.

Example: 4728 + 3695
  • Units: 8 + 5 = 13. Write 3; carry 1.
  • Tens: 2 + 9 + 1 = 12. Write 2; carry 1.
  • Hundreds: 7 + 6 + 1 = 14. Write 4; carry 1.
  • Thousands: 4 + 3 + 1 = 8. Carry becomes 0.
Answer: 8423

Q2. What if a five-digit number is added to a three-digit number?

Example: 42536 + 178 Align the numbers on the right: 
  42536
+   178
-------
  42714
Units: 6 + 8 = 14, write 4 and carry 1.
Tens: 3 + 7 + 1 = 11, write 1 and carry 1.
Hundreds: 5 + 1 + 1 = 7.
The remaining digits 2 and 4 have no matching digits in 178. Treat the missing digits as zero: the remaining digits are copied into the answer.
Answer: 42714. A fully precise algorithm should explicitly say to treat missing digits as zero.

Q3. Why should place-value columns be aligned from the right?

The rightmost column contains units, the next contains tens, then hundreds and thousands. Aligning from the right puts units under units, tens under tens and so on. This ensures that only digits of the same place value are added.

Q4. Why can the carry never exceed 1?

The greatest possible column sum is 9 + 9 + 1 = 19. Since 19 contains only one complete group of ten, the carry can only be 0 or 1. It can never be 2 or more.

Q5. What happens if the final-carry step is omitted?

Case where the answer is still correct:
123 + 456 = 579. There is no final carry, so omitting that step makes no difference.

Case where the answer fails:
999 + 1 produces 000 in the three existing columns and leaves a final carry of 1. Without writing that carry, the answer would incorrectly be 000 instead of 1000.

Think and Reflect — Addition

1. Why does the column-addition algorithm work?

Every digit represents a place value: units, tens, hundreds and so on. When a column sum reaches 10 or more, its units digit stays in that column and the extra ten is carried to the next column. Since ten units equal one ten, ten tens equal one hundred, and so on, carrying preserves the total value. Repeating this process gives the correct sum.

2. How can the algorithm add decimal fractions?

Align the decimal points first. Add zeros to the end of a decimal if necessary, so both numbers have the same number of decimal places. Add the columns from right to left and put the decimal point in the answer directly below the aligned decimal points.

Example: 4.7 + 12.85 = 4.70 + 12.85 = 17.55.

Exercise Set 11.2 — Lists, Divisors and LCM

Q1. Write algorithms to find elements unique to each of two increasing lists.

(i) Elements in List 1 that are not in List 2:
  1. Create an empty result list.
  2. Check each element of List 1.
  3. If an element does not occur in List 2, add it to the result list.
  4. Report the result list.
(ii) Elements in List 2 that are not in List 1: Use the same steps, but switch the roles of List 1 and List 2.

Example: List 1 = [1, 2, 3, 6] and List 2 = [1, 3, 5, 9].
(i) Result: [2, 6].
(ii) Result: [5, 9].

Q2. Describe an algorithm to calculate the LCM of two numbers.

Method 1: List the multiples of each number in increasing order. The first multiple appearing in both lists is their LCM.

Method 2: Find the GCD first and use:
LCM(m,n) = (m × n) ÷ GCD(m,n)
Example: Find LCM(18,24).
24 = 1 × 18 + 6, and 18 = 3 × 6 + 0, so GCD = 6.
LCM = (18 × 24) ÷ 6 = 432 ÷ 6.
Answer: 72.

Q3. Divisors occur in pairs. Answer both parts.

(i) How many numbers must be checked?
A divisor d pairs with n ÷ d. One number in each pair must be at most √n. Therefore, checking possible divisors from 1 up to √n is enough. Whenever j divides n, record both j and n ÷ j, taking care not to record a square root twice when n is a perfect square.

Example: For 18, √18 is about 4.24. Check 1, 2, 3 and 4. This finds the pairs (1,18), (2,9) and (3,6).

(ii) Would the original GCD algorithm still work unchanged?
No. Divisor pairs are not automatically produced in increasing order. The original method uses the last element of an increasing list to find the GCD. With unsorted pairs, we must either sort the list or keep track of the largest common divisor found.

Think and Reflect — Divisors and GCD

1. Find the divisors of 15, 135 and 775. How does the amount of work grow?

Divisors of 15: 1, 3, 5, 15. The basic algorithm checks 15 numbers.
Divisors of 135: 1, 3, 5, 9, 15, 27, 45, 135. It checks 135 numbers.
Divisors of 775: 1, 5, 25, 31, 155, 775. It checks 775 numbers.

The basic method checks every number from 1 to n, so the work grows in proportion to n. Checking only up to √n and using divisor pairs can reduce the work.

2. What if we check common divisors backwards from min(m,n)?

Start with the smaller of m and n and test downward. The first number that divides both exactly is the GCD, because all larger possible candidates have already been checked and rejected.

Example: m = 12 and n = 18. Start at 12. The first common divisor encountered is 6. Therefore, GCD(12,18) = 6, and the algorithm can stop immediately.

Exercise Set 11.3 — Improving the GCD Algorithm

Q1. What changes if divisors are examined from n down to 1?

The set of divisors does not change, but their order becomes decreasing rather than increasing.

Example: Divisors of 12 in decreasing order are 12, 6, 4, 3, 2, 1.

If both divisor lists are decreasing, their common divisors will also be found in decreasing order when checked consistently. The largest common divisor is then the first common divisor, or the leftmost entry, rather than the rightmost.

Q2. What happens when common divisors are checked backwards?

Let k = min(m,n). Test k, k − 1, k − 2, and so on. As soon as a number divides both m and n exactly, report it as the GCD and stop. It is the greatest common divisor because every larger candidate was already checked.

Example: For 12 and 18, begin with 12 and move downward. The first common divisor is 6, so GCD(12,18) = 6.

Q2. Explain why the common divisors of m and n are the same as those of n and the remainder.

Assume m ≥ n. By division, write:
m = qn + r, where r = m mod n.
Forward: If d divides both m and n, then d divides qn. It must also divide their difference m − qn = r. Thus d divides both n and r.

Reverse: If d divides both n and r, then it divides qn and r. Therefore, it divides qn + r = m. Thus d divides both m and n.

So both pairs have exactly the same common divisors, which proves:
GCD(m,n) = GCD(n, m mod n)

Q3. Write an algorithm to test whether n is prime.

  1. Find all positive divisors of n.
  2. Count the divisors.
  3. If there are exactly two divisors, report that n is prime.
  4. Otherwise, report that n is not prime.
Example: Divisors of 7 are [1,7], so 7 is prime. Divisors of 8 are [1,2,4,8], so 8 is not prime.

Note: This test assumes n is greater than 1; 0 and 1 are not prime.

Q4. Write an algorithm to find the prime divisors of n.

  1. Find the complete list of divisors of n.
  2. Create an empty list for prime divisors.
  3. Check each divisor using the prime-number test.
  4. Add only prime divisors to the result list.
  5. Report the result.
Example: Divisors of 18 are [1,2,3,6,9,18]. The prime divisors are [2,3].

Q5. Describe a prime-factorisation algorithm and how to compare two results.

Start with the number n and an empty list of prime/exponent pairs. Find the smallest prime that divides the current number. Count how many times it divides exactly, record the prime and its exponent, and divide it out. Repeat until the remaining number is 1.

(i) Represent 180:
180 = 2² × 3² × 5¹
As pairs: [(2,2), (3,2), (5,1)].

(ii) Compare two factorisations:
Align the prime numbers in both lists. Treat a missing prime as having exponent zero. For the GCD, use the smaller exponent of each shared prime. For the LCM, use the larger exponent of every prime appearing in either number.

Example: 180 = 2² × 3² × 5 and 84 = 2² × 3 × 7.
GCD = 2² × 3 = 12.
LCM = 2² × 3² × 5 × 7 = 1260.

Quick Revision

  • An algorithm must be clear, ordered and precise.
  • Column addition uses carrying to move extra tens to the next place value.
  • Divisor pairs can reduce checks to about √n.
  • Euclid's subtraction method repeatedly subtracts the smaller number.
  • The division method uses remainders and is generally much faster.
  • GCD uses the smaller exponents in prime factorisation; LCM uses the larger exponents.
